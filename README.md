# Thập Nhị Chiến Ký

Game hành động đi cảnh trên trình duyệt: ba nhân vật vượt 12 vùng đất thu phục 12 con giáp, lên tầng Ngũ Hành đấu 5 Đại Pháp Sư, rồi vào nghĩa trang trong núi hạ Tà Sư.

## Chơi
Mở `index.html` bằng trình duyệt, hoặc vào trang GitHub Pages của repo này.

## Điều khiển
- ← → di chuyển, bấm 2 lần để chạy
- ↑ / V nhảy (bấm 2 lần: nhảy đôi), ↓ thủ hoặc nhảy xuống khỏi bục
- X bắn/chém, giữ để nạp · Z lướt · C thủ
- A · S · D kỹ năng · Enter tạm dừng
- B rương báu · Q đổi tầng · M bật/tắt nhạc · P toàn màn hình
- Điện thoại: cần điều khiển ảo và nút cảm ứng

## Cấu trúc
- `index.html`: toàn bộ game (HTML, CSS, JavaScript trong một file)
- `music/`: nhạc nền (menu, boss, tầng 2)
